# Bank Management System (Java)

## Description
A console-based Java application that simulates basic banking operations such as account creation, deposit, withdrawal, and balance inquiry.

## Features
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction Handling

## Tech Stack
- Java
- Object-Oriented Programming (OOP)

## Project Structure
- model → Contains data classes like Account, Customer
- service → Interfaces defining operations
- serviceimpl → Implementation of business logic
- client → Main class to run application

## How to Run
1. Clone the repository:
   git clone https://github.com/your-username/bank-management-system-java.git

2. Open in Eclipse or IntelliJ

3. Run the main class
